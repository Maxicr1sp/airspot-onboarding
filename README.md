# Airspot onboarding prototype

A clickable, front-end-only prototype of a self-serve CTV onboarding flow, from sign-up to first campaign launch, plus campaigns, results, library, reporting and admin views.

- **Run it:** open `index.html` in a browser. There's no build step: React, htm and fonts load from CDNs.
- **Demo:** use "Fill demo details" on sign-up, or **⚙ Prototype controls** (bottom right) to jump between steps, switch the A/B variants (payment position, billing model) and watch tracked events.
- **Data:** everything is simulated in the browser; campaigns and media persist in `localStorage`.
